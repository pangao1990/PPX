# 客户端交互验收清单

每次发布前，既要运行 `pnpm check`、`pnpm build`、`pnpm verify:installer`，也要打开新生成的客户端逐项点击。应在 macOS、Windows、Linux 各自执行；浏览器中的模拟接口不能代替原生文件选择器和安装包验收。

## 准备

使用两个专用测试文件，一个含中文文件名，一个含空格。便签测试先记录原有内容，测试结束后恢复。更新测试应使用自己控制的测试发布源和测试安装包，不覆盖生产应用或用户数据。

## 正常操作

| 入口 | 操作与预期结果 |
| --- | --- |
| 首次启动 | 显示“Python 已连接”，页面可滚动，无白屏或脚本异常 |
| 工作台 | 中文、emoji 和首尾空格名字可提交；回车等同点击；空白名字不可提交 |
| 本机用户名 | 点击后出现真实系统用户名；最近调用显示成功 |
| 页面导航 | 三个侧栏按钮、两张快捷卡片、品牌入口均到达正确页面；切换后回到顶部 |
| 开发文档 | 侧栏和“开始构建”均打开内置说明；断网后仍可阅读 |
| 外部链接 | 逐个点击 GitHub、项目仓库、版本发布、问题反馈、在线介绍站；系统浏览器目标正确且页面非 404，应用本身仍保留 |
| 文件 | 单选、多选、中文名和空格名均回传完整路径；取消保留已有列表 |
| 目录 | 选择后显示完整路径；取消保留原目录并提示 |
| 便签 | 编辑显示未保存；保存成功后按钮禁用；切换页面和重启客户端均保留已保存内容 |
| 清空便签 | 清空后为空，重启仍为空；恢复测试前的数据 |
| 最近调用 | 最多五条；清空后显示空状态 |
| 检查更新 | 当前版本无更新时显示说明；有更新时显示发布说明和发布页入口 |
| 更新下载 | 进度更新、后台下载、重新打开进度、取消下载均正常；取消后能重新下载 |
| 下载完成 | 显示校验通过和安装包路径；打开安装包交给系统；关闭弹窗后仍有“更新已下载”入口 |
| 窗口 | 缩小、放大、关闭后重新打开；窄窗口不横向溢出，低高度窗口可滚动侧栏，文档和 GitHub 入口仍可操作 |

## 异常操作

- 普通浏览器无 Python 桥接时，显示预览提示并禁用桌面按钮；“重新连接”可重试，页面导航不受影响。
- 首次便签读取失败时禁止保存和清空，保留“重新读取”入口；读取成功后解除禁用。
- 保存失败时保留草稿和未保存状态，允许重试；错误提示能在当前视区看到并关闭。
- 系统无法打开浏览器时显示错误和原网址，不能假装页面已成功打开。
- 更新检查断网时结束等待状态，显示失败信息，允许再次检查。
- 下载中断或校验失败时不提供未校验的安装包，保留重新下载入口。
- 下载期间关闭弹窗只能通过“后台下载”；取消按钮不能重复触发。
- 快速重复点击不重复发起同一个任务；失败后按钮重新可用。

## 2026-09-05 本地结果

macOS arm64 的打包客户端已验证真实 Python 问候、用户名、原生多选与取消、目录选择、便签保存和重启恢复、清空、内置文档、全部外部入口、更新检查与关闭。原始文件过滤器也做了独立对照，多选正常；自动化工具点击文件名没有选中列表项的现象不列为产品缺陷。

浏览器共通过 28 个常规检查点、9 个异常与恢复检查点及低高度侧栏点击检查，覆盖成功与失败状态、更新进度和取消/重试/完成、390px / 600px / 1280px 布局与 960×360 低高度窗口。更新异常通过测试桥接注入，仅存在于测试浏览器，未包含在生产源码或安装包中。真实下载的校验、取消和原子写入由 Python 回归测试使用本地 HTTP 服务验证。

本地脚本、日志、截图位于忽略目录 `output/playwright/`：`client-regression.js`、`client-regression.log`、`client-*-desktop.png`、`client-*-mobile.png`。如已安装 Playwright CLI，可先启动 GUI 开发服务，再使用独立浏览器会话运行此脚本；它会注入测试桥接，不能用于真实数据会话。

尚未执行 Windows/Linux 真机点击、正式公网更新安装、系统签名、公证与卸载验收。2026-09-05 新版介绍站已通过 GitHub Pages Actions 部署；客户端保留离线入门说明，同时提供最新版在线文档与 V5 归档两个入口。
